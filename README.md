# Overcommitted

Juego de navegador en pixel art: un dev buscando laburo malabarea freelance, agentes de IA que alucinan, entrevistas y notebooks prendidas fuego. Rondas de 5 minutos, estilo Overcooked.

```bash
npm install
npm run dev     # http://localhost:5173
npm run check   # typecheck + lint + tests + build
```

Diseño y plan en [`docs/`](docs/).
